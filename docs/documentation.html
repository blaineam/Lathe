Installation

// Package.swift
dependencies: [
    .package(url: "https://github.com/blaineam/Lathe.git", from: "1.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "LatheVideo", package: "Lathe"),
        .product(name: "LatheMeta",  package: "Lathe"),
    ])
]

Or take the Lathe umbrella product, which re-exports everything except the two that carry conditions — see Licensing.

Start

The shape of it

Four ideas run through every module, and knowing them makes the rest predictable.

A request goes in, a result comes out

Every operation is a value you build and a value you get back. Nothing is configured by mutating a shared object, so two concurrent jobs cannot change each other’s settings.

Capability is asked, never assumed

Whether this device can encode AVIF is a question for the device. An #available check is a guess dressed up as a fact, and it is wrong on the machines that matter.

Progress and cancellation are the same channel

A ProgressHandle reports and answers “keep going?”. Returning false unwinds through the same path a cancelled task does, and partial files are removed.

Nothing is overwritten until it has succeeded

Work happens in a directory beside the destination, and the destination is written once, at the end, by a move. A crash leaves the old file intact rather than truncated.

What each one does

LatheCore

The vocabulary. Everything the other modules agree on: where media comes from, how work is described, how progress and cancellation travel, and how concurrent work is rationed. Nothing here encodes anything.

MediaSourceMediaDataTransportURLSessionMediaTransportProgressHandleLatheErrorBulkRunResourcePoolWorkloadChapterChapterTrackQualityTargetResizeTargetMetadataPolicyContentFingerprint
// A local file, or a URL streamed in place — callers do not
// have to download media before handing it to Lathe.
let source = try MediaSource(URL(string: "https://example.com/clip.mp4")!)

// Concurrency is rationed per workload, not globally: video contends
// for a fixed number of hardware encoders, recognition for one Neural
// Engine, network for nothing local at all.
let results = await BulkRun(pool: .automatic).run(
    urls.map { BulkRun.Item($0, workload: .video) }
) { item in try await transcode(item) }

LatheVideo

Probing, frames and transcoding. Container inspection without decoding, frame extraction, and VideoToolbox transcoding with constant-quality control. Chapters survive.

MediaProbeMediaInfoMediaTrackInfoVideoTranscoderVideoTranscodeRequestVideoCodecRateControlBFramePolicyFrameExtractorFrameSelectionFrameAccuracyAudioDispositionFFProbeReport
// A strip of stills, with one generator for the whole run. A count
// samples the middle of each slice, because the first and last frames
// of a video are usually black.
let stills = try await FrameExtractor().frames(
    from: video, into: folder, selection: .count(12))

// Reads container headers only, so a four-hour film costs what a
// four-second clip costs.
let info = try await MediaProbe().inspect(source)
print(info.duration, info.tracks.map(\.codec))

var request = VideoTranscodeRequest(source: source, destination: out)
request.codec = .hevc
request.rateControl = .quality(0.65)   // constant quality, not bitrate
let result = try await VideoTranscoder().run(request)

LatheImage

Stills and animations. ImageIO for HEIC, AVIF, JPEG, PNG, GIF, TIFF and JPEG 2000, plus vendored libwebp for WebP. Resizing, re-encoding, and metadata rewriting that does not re-encode.

// rather than guessed from an OS version.

request.quality = .init(0.8)
request.resize = .longestSide(2048)
let result = try await ImageEncoder().run(request)

LatheAudio

Encoding and loudness. AudioToolbox for AAC, ALAC, Opus and FLAC, with loudness probing and channel policy. Chapters survive here too.

AudioTranscoderAudioTranscodeRequestAudioCodecAudioContainerAudioInspectorAudioFileInfoLoudnessProbeMeanVolumeChannelPolicyLossySourceRuleAudioSkipReason

// has to be asked for by name.
var request = AudioTranscodeRequest(source: source, destination: out)
request.codec = .aac
request.lossySources = .skip        // .allow to override

let outcome = try await AudioTranscoder().run(request)
if case let .skipped(reason) = outcome { print(reason) }

LatheMP3

MP3, because the system will not. CoreAudio decodes MP3 and refuses to encode it. LAME sits behind its own product boundary so the LGPL stays quarantined — link it only if you want it — and ships as its own dynamic lame.framework, so an app can let a user replace it. mpglib is GPL and is excluded.

MP3EncoderMP3Mode
// A separate product. Nothing else in Lathe links LAME, so an app
// that does not want the LGPL simply does not depend on this.
let encoder = MP3Encoder()
let result = try await encoder.encode(
    source, to: out, mode: .joint, quality: 0.6)

LatheMeta

Reading and writing metadata. One model over four very different backends: iTunes-style ilst atoms for video, ImageIO dictionaries for stills, PDF document attributes, and a hand-written ID3 reader and writer for MP3 — which has no container for AVFoundation to work with. Subtitles too: SubRip and WebVTT parsed, muxed into MP4/MOV as selectable tracks without re-encoding, and extracted back out.

MediaMetadataMetadataReaderMetadataWriterMetadataStoreArtworkArtworkRoleShowInfoTrackInfoMediaKindMetadataDatesSubtitleMuxerChapterWriterSubtitleParserSubtitleCueSubtitleLanguage
// `stik` is what decides Movies vs TV Shows in Apple players;
// EXIF is not used by video at all, which surprises people.
var metadata = try await MetadataReader().read(source)
metadata.kind = .tvEpisode
metadata.show = ShowInfo(name: "Example", season: 2, episode: 4)
metadata.artwork = [Artwork(data: jpeg, format: .jpeg, role: .cover)]
try await MetadataWriter().write(metadata, to: file)

LatheDoc

PDFs and comic archives. Page reordering, insertion, removal and merging for PDF and CBZ, recompression, and a Vision-backed text layer. Remote archives can be counted with two range requests instead of a download.

DocumentEditorDocumentInspectorDocumentKindPDFRecompressorPDFMetadataEditorPDFTextLayerWriterComicArchiveRecompressorPageReferenceTextRecognitionAccuracy
// A CBZ is a ZIP, and its readers sort by filename — so reordering
// pages means renaming them, zero-padded, not just reshuffling.
let editor = DocumentEditor()
try await editor.reorder(pages, in: comic, to: out)

// The central directory is at the end of a ZIP, so counting the
// pages in a remote CBZ is two range requests, not a download.
let count = try await DocumentInspector().pageCount(at: remoteURL)

LatheLookup

Artwork and subtitles. Providers for TMDb and OpenSubtitles behind one protocol, with a filename parser that turns release names into a query. You supply the API key; Lathe ships none.

MetadataProviderTMDbProviderOpenSubtitlesProviderMediaTitleParserLookupQueryMetadataMatchSubtitleInstallerSubtitleCandidateSubtitleDocumentProviderCredentialsHTTPTransport
// The key is the caller's. A library that ships its own key ships
// one rate limit shared by every application that uses it.
let provider = TMDbProvider(credentials: .init(apiKey: key))
let query = MediaTitleParser().parse("Example.S02E04.1080p.WEB-DL.mkv")
let matches = try await provider.search(query)

LatheFetch

Extractors, on their own terms. A CPython runtime, a pure-Swift wheel installer, and drivers for yt-dlp and gallery-dl. Neither tool is vendored or shipped — both are fetched at run time, by a user who asked for them, into a directory the application owns.

MediaFetcherGalleryFetcherMediaListingMediaFormatFormatSelectorFormatPolicyPlaylistStreamMuxerPythonRuntimePythonPackageInstallerJavaScriptEngineMediaFetchError
// yt-dlp shells out to ffmpeg to join video and audio, and iOS has
// no subprocesses — so Lathe never asks for a compound format and
// joins the two streams itself with AVAssetWriter.
let listing = try await fetcher.listing(for: url)
let media = try await fetcher.download(url, to: destination)

// gallery-dl answers a different question: what files are on this
// page. So it returns a list of paths rather than one.
let haul = try await gallery.download(url, into: folder, limit: 50)
Rules

Licensing, kept at the product boundary

Lathe is Apache-2.0. Two modules carry conditions, and rather than explain them in a README they are separate products, so the boundary is enforced by the build rather than by a note.

ProductCarriesLicenceIn the umbrella?
LatheCore, LatheVideo, LatheImage, LatheAudio, LatheDoc, LatheMeta, LatheLookup System frameworks, libwebpApache-2.0 / BSD Yes
LatheMP3LAME, as a dynamic frameworkLGPL-2.0-or-later Opt in
LatheFetchCPython; fetches yt-dlp / gallery-dl at run time PSF; tools not shippedOpt in

What “not shipped” means

yt-dlp is Unlicense and gallery-dl is GPL-2.0. Neither is vendored, linked, or included in any build product. They are fetched from PyPI at run time, into a directory the application owns, by a user who asked for them — the same arrangement anyone running pip install arrives at. LAME’s mpglib is GPL and is excluded from the vendored source entirely.

Rules

Platforms, and the one that shapes everything

iOS 17 and macOS 14, arm64. The iOS floor is the constraint that decided the whole design: PEP 730 removes process spawning, and fork/exec was never available there anyway. Every tool that works by launching a binary is therefore not an option, and that is why this exists at all.

The macOS build makes no use of the difference. Anything that works on the Mac works on the phone, which is the only way to be sure the phone is not an afterthought.
