Why it exists

Porting the C tools is the wrong answer

Most media tooling on Apple platforms is a command-line binary behind a process spawn. That works on a desktop and cannot work on a phone.

On an iPhone there is no fork and no exec. A media feature that shells out to ffmpeg is a feature the iPhone version will never have, and the usual response is to port the C tools and ship them inside the app — megabytes of codecs, licences to audit, and a second copy of work the device already knows how to do.

Because it does know how. ImageIO writes HEIC, AVIF, JPEG, PNG, GIF and TIFF. AVFoundation reads containers without decoding them and extracts frames. VideoToolbox encodes H.264 and HEVC on the media engine at a constant quality. Vision reads text. None of it costs a licence, and most of it runs in silicon built for the job.

Lathe is the thin, well-tested layer over those frameworks — plus the few libraries that fill the gaps they really leave.The design, in one sentence

The gaps are real and there are three. Nothing Apple ships writes WebP, so libwebp is compiled in from source. Nothing writes MP3, so LAME ships as its own replaceable framework, as its licence asks. And no Apple chip encodes AV1, so SVT-AV1 runs on the CPU in a product of its own, for the apps that want it.

Everything else is the system doing the work it was built for — asked what it can do rather than assumed, reporting progress through one channel that can also say stop, and never overwriting a file until the new one is whole.

The departments

What it does

Every module is its own library product, so an app links exactly what it uses — and an App Store target never links what it should not.

VIDEO

Probe, frames, transcode

Container headers without decoding, stills at any time or count, and H.264 or HEVC on the media engine with chapters kept.

LatheVideo
IMAGE

Stills and animations

HEIC, AVIF, JPEG, PNG, TIFF, GIF and WebP — still or animated — with the device asked what it can write first.

LatheImage
AUDIO

Loudness and codecs

AAC, ALAC, Opus and FLAC, a mean volume that matches the familiar filter, and an audibility check that stops early.

LatheAudio
META

Tags, chapters, subtitles

One model over iTunes atoms, ID3, EXIF and PDF; chapter tracks written in; SubRip and WebVTT muxed as real tracks.

LatheMeta
DOC

PDFs and comics

Reorder, insert, remove and merge PDF and CBZ pages, add a searchable text layer, and turn a folder of frames into a book.

LatheDoc
AV1

AV1, on the CPU

SVT-AV1 into MP4, carrying rotation, colour and HDR, for the apps that want the smallest files and can wait for them.

LatheAV1
MP3

MP3, replaceably

LAME as its own dynamic framework, so the LGPL is kept where it belongs and a user can swap it.

LatheMP3
SWF

Flash, recovered

The images and sounds a Flash movie stores, extracted as files — and what it draws, rendered by a bundled Ruffle.

LatheSWF · LatheSWFRender
LOOKUP

Titles and artwork

TMDb and OpenSubtitles behind one protocol, with a release-name parser. The key is always the caller's own.

LatheLookup

A detail worth the space

The audibility cliff

Mean volume over a whole file is how most tools answer does this have sound? — and it is quietly wrong.

Ten minutes containing two seconds of speech averages about −45 dBFS: by that number, indistinguishable from a file with nothing in it. That is not a corner case. It is an ordinary phone video with one sentence in it.

So Lathe answers the question the caller has. meanVolumeDB reports the familiar statistic, so existing thresholds keep working; hasAudibleAudio reads short windows and returns the moment it knows. A loud file is decided in its first second.

// A measurement, and a decision that stops as soon as it has an answer.
let volume = try await LoudnessProbe().meanVolumeDB(url: source)
let audible = try await LoudnessProbe().hasAudibleAudio(url: source)

// Re-encoding a lossy source is refused unless asked for.
let outcome = try await AudioTranscoder().transcode(
    source: source, to: out, codec: .aac, quality: .quality(0.5))

Install

One line, then only what you use

Add the package, then depend on the products your target needs. The Lathe umbrella re-exports the media modules and deliberately leaves out anything that downloads, needs a licence decision, or runs on the CPU for minutes.

// Package.swift
.package(url: "https://github.com/blaineam/Lathe.git", from: "1.1.3")

// then, per target
.product(name: "LatheVideo", package: "Lathe"),
.product(name: "LatheAV1", package: "Lathe")
