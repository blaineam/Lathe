Why it exists

Porting the C tools is the wrong answer

Most media tooling on Apple platforms is a command-line binary behind a process spawn. That works on a desktop and cannot work on a phone.

Install

One line, then only what you use

Add the package, then depend on only the products your target needs.

// Package.swift
.package(url: "https://github.com/blaineam/Lathe.git", from: "{{version}}")

// then, per target
.product(name: "LatheVideo", package: "Lathe"),
.product(name: "LatheAV1", package: "Lathe")
