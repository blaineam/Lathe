Installation

Add the package once, then depend on products per target. The newest release is {{version}}.

// Package.swift
dependencies: [
    .package(url: "https://github.com/blaineam/Lathe.git", from: "{{version}}"),
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "LatheVideo", package: "Lathe"),
        .product(name: "LatheMeta", package: "Lathe"),
    ]),
]

Or take the Lathe umbrella, which re-exports the six media modules and nothing that carries a condition.

The shape of it

Four ideas run through every module. Knowing them makes the rest predictable.

A request in, a result out

Every operation takes values and returns one. Nothing is configured by mutating a shared object, so two jobs cannot change each other's settings.

Capability is asked, not assumed

Whether this device can write AVIF is a question for the device. An OS-version check is a guess, and it is wrong on the machines that matter.

Progress can say stop

A ProgressHandle reports and answers “keep going?”. Stopping unwinds through the same path as a cancelled task, and partial files are removed.

Nothing is overwritten until it worked

Work goes to a scratch file beside the destination and replaces it in one move at the end. A crash leaves the old file intact.

probe · frames · transcode

Container inspection without decoding, frame extraction with one generator per run, and VideoToolbox transcoding at a constant quality. Chapters and tags survive the rewrite.

LatheImage

stills · animations

ImageIO for HEIC, AVIF, JPEG, PNG, GIF and TIFF, libwebp for WebP — still and animated — and resizing that respects orientation.

{{snippet:image}}

LatheAudio

loudness · codecs

AudioToolbox for AAC, ALAC, Opus and FLAC, with a loudness probe that matches the familiar filter and a channel policy that downmixes only when asked.

{{snippet:audio}}

LatheMeta

tags · chapters · subtitles

One model over four stores: iTunes atoms for video and audio, ImageIO properties for stills, PDF attributes, and ID3 for MP3. Chapters are written as real chapter tracks and subtitles as selectable tracks — both by remux, with nothing re-encoded.

{{snippet:tags}}
{{snippet:chapters}}

LatheDoc

PDF · CBZ

Reorder, insert, remove and merge pages across PDF and CBZ, recompress them, and add a Vision text layer. A remote CBZ is counted with two range requests, not a download.

{{snippet:documents}}

LatheAV1

SVT-AV1

No Apple device encodes AV1 in hardware, so this is SVT-AV1 on the CPU: several times real time on a Mac, slower on a phone, and the smallest files of any codec here. Rotation, colour and HDR are carried; audio is passed through.

{{snippet:av1}}

LatheMP3

LAME

Apple decodes MP3 and will not encode it. LAME ships as its own dynamic framework, so an app can let a user replace it, as the LGPL asks — and nothing else in Lathe links it.

{{snippet:mp3}}

LatheSWF

extraction · rendering

Flash movies, both ways: the JPEGs, PNGs and sounds they store, recovered as files; and what they draw, rendered frame by frame by a bundled Ruffle in an offscreen web view.

{{snippet:flash}}

LatheLookup

TMDb · OpenSubtitles

Titles, episode numbers, artwork and subtitles, behind one protocol, with a parser that turns a release name into a query. You supply the key; Lathe ships none.

{{snippet:lookup}}

LatheCore

the vocabulary

Where media comes from, how progress and cancellation travel, and how concurrent work is rationed — per kind of work, because video contends for encoders and recognition for the Neural Engine.
