01 — What it is

A queue, a browser, and somewhere for it all to land

The field at the top takes URLs separated by spaces or newlines, so pasting a column out of a spreadsheet works without editing it first. Each becomes a row that reports its own state, and the rows run concurrently under a network lane — the same machinery the library uses everywhere else.

A direct link to a media file needs nothing installed at all.

Browse signed in, in tabs

A real web view per tab, with a persistent store, so signing in sticks and switching panes finds the page as you left it. Downloading from a tab hands the extractor that site’s cookies and nothing else.

WKWebView · per-tab sessions

Mute a tab from the tab

A tab that starts talking can be silenced without switching to it. There is no public API for muting a web view — the supported calls stop playback rather than quiet it — so it is an injected script.

Per-tab audio

From your phone

A one-step Shortcut on the iOS share sheet appends a link to a file in iCloud Drive. Lathe watches the folder and starts the download on the Mac, even if it was asleep when you shared.

iCloud Drive · Shortcuts

Tor, built in

The daemon is linked into the app, not launched as a process — the arrangement that also works where a bundled binary could not be run at all. Browsing and downloading both go through it.

tor_run_main · 15 MB slimmed

Two extractors, routed

yt-dlp for video and audio, gallery-dl for images. Which one handles a link is decided per link: a named yt-dlp extractor wins, because its generic one claims every URL ever written.

yt-dlp · gallery-dl

Just this, or everything

A link that names both an item and a collection means the item, which is what copying a YouTube link actually gives you. Switch the row to “Everything” to take the whole playlist or gallery.

Per-row scope

Hand off to Sami

Finished downloads go straight to Sami for compression or conversion, with the operation and preset you chose travelling with them. If Sami is not installed the file simply lands in your folder.

Handoff · one delivery
02 — Onboarding

Lathe ships no extractor, and says so

Nothing is bundled. On first run a banner offers to install yt-dlp and gallery-dl from PyPI into an app-private Python environment — nothing is written outside the app’s own container, and no system Python is touched.

That is not a limitation dressed up as a feature. It is what keeps this a downloader you assembled rather than one that arrives with a thousand sites baked into it, and it is the difference between a tool and a liability.

The installer is pure Swift

There is no pip here. Wheels are resolved from PyPI metadata, verified by hash, and unpacked by the interpreter’s own zipfile. Dependency resolution honours PEP 508 markers and extras, so installing gallery-dl installs what gallery-dl needs and nothing that only its extras need.

03 — Privacy

Fail closed, or do not offer it

Proxy routing is checked with a real SOCKS5 handshake before anything downloads — not just a connection, because anything at all can be listening on a port and a stale tunnel that passes a connection test would fail much later with an error about the response not being media.

If the proxy is not there, the download fails. A downloader that quietly abandons the proxy it was told to use is worse than one that has no proxy option at all: you would believe something about your traffic that is not true, and nothing in the interface would contradict you.

04 — The hand-off

Getting a file into a sandboxed app is the whole problem

Sami is sandboxed, as anything from the App Store is. It cannot read a folder Lathe picked, it cannot see Lathe’s preferences, and the two do not share a container — that would need both to be signed into the same App Group, which a locally built tool is not.

What a sandbox does admit is a file the system handed it. Opening a document in another application grants that application access to exactly those files, through the same machinery that makes double-clicking work.

So the request travels as one of the files.

Lathe writes a small handoff document — what to do, which preset, where the results should go — and opens it in Sami alongside the media it describes. One delivery. The options and the files arrive together or not at all, rather than as a URL and an open that can land in either order, or only one of which lands.

The format is versioned, and a receiver that meets a newer one says so rather than acting on the half it understood.

05 — Building it

One script, no project file

# Builds build/Lathe.app
./App/make-app.sh

A hand-assembled bundle rather than an Xcode project, on purpose: the whole repository builds with swift build, and a .xcodeproj would be a second source of truth to keep in step by hand.

The bundle is not signed, so the first launch needs right-click → Open. The icon is a layered Icon Composer document compiled by actool, so macOS draws the squircle, the glass and the tinted appearances itself.
