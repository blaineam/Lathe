What it is

A queue, a browser, and somewhere to land

The field at the top takes links separated by spaces or new lines, so a column pasted from a spreadsheet works as it is. Each becomes a row that reports its own progress, and the rows run side by side.

Browse signed in

A real browser with tabs and a persistent store, so signing in sticks. Downloading from a tab hands over that site's cookies and nothing else, and a noisy tab mutes from the tab.

per-tab sessions

From your phone

Share a link to the Lathe Shortcut and it asks two quick questions — just this or everything, and where the files should land. Lathe picks the answers up off iCloud Drive and starts the download on the Mac, without anyone touching it.

iCloud Drive · Shortcuts

Tor, built in

The daemon is linked into the app, not launched beside it. Browsing and downloading both go through it when it is on.

in process

Two extractors, routed

yt-dlp for video and audio, gallery-dl for images, chosen per link — and a plain media URL needs neither.

yt-dlp · gallery-dl

This, or everything

A link that names an item and a playlist means the item. Switch the row to take the whole playlist or gallery.

per-row scope

Out of the way

In the Dock, in the menu bar only, or fully in the background — open it again to see the window, and the Dock icon comes and goes with it.

three presences
Onboarding

It ships no extractor, and says so

Nothing is bundled. On first run a banner offers to install yt-dlp and gallery-dl into a Python environment inside the app's own container. No system Python is touched.

No pip

Wheels are resolved from PyPI's metadata, verified by hash and unpacked by the interpreter's own zip support — all in Swift.

Markers and extras

Dependency resolution honours PEP 508, so installing gallery-dl installs what it needs and nothing only its extras need.

A tool, not a liability

A downloader you assembled is a different thing from one that arrives with a thousand sites built in.

Privacy

Fail closed, or do not offer it

A proxy is checked with a real SOCKS5 handshake before anything downloads — not just a connection, because anything can be listening on a port.

If the proxy is not there, the download fails. A downloader that quietly drops the proxy it was told to use is worse than one with no proxy option: you would believe something about your traffic that is not true.

The hand-off

Lathe downloads it. Sami makes it smaller.

Sami is sandboxed, as anything from the App Store is: it cannot read a folder Lathe picked or see Lathe's settings. What a sandbox does accept is a file the system hands it — so the request travels as a file.

  1. Choose a download folder once, and whether finished files go to Sami.
  2. Pick compression or conversion, and a preset.
  3. Lathe opens a small request document in Sami together with the media — one delivery.
  4. Sami picks both up and gets to work. Without Sami, the file simply lands in your folder.
Build it yourself

One script, no project file

# builds App/build/Lathe.app
./App/make-app.sh

The whole repository builds with swift build; an Xcode project would be a second source of truth. Releases are built by CI, signed with a Developer ID and notarized by Apple, and the disk image is stapled so it opens offline.
